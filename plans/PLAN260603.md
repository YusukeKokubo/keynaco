# PLAN260603: 文節分割を AzooKey Desktop（`.selecting`）に寄せる

## 目的

Space 後の文節選択モードで、AzooKey と同様に **左端文節の長さをエンジン候補の `composingCount` で決め**、フラットな候補リストから表層を選び、Enter で部分確定 → 残りで再変換する。

見た目だけ合わせるのではなく、**境界の正本**を Desktop と同型にし、keynaco 独自の読みルール（suffix 剥がし・`segmentize` 依存）による誤分割をなくす。

**Phase 1 で確定したこと**

- suffix / segmentize 境界は **`こんにちは` を壊す**（`こんにち|は` + 誤変換）。除去は正しい方向。
- 除去だけでは `firstClauseResults` が空に近く、#1 #2 #6 は **全文境界に戻る**。

**Phase 2 で確定したこと**

- 部分長候補の多くは **raw `mainResults`** にある（例: `あなた:3`, `こんにち:4`）。`firstClauseResults` 単体では足りない。
- Desktop 同型の **`mergedFirstClauseResults`**（firstClause 全文時は main のみ）+ 文節用 Options で **suffix なし再現**可能。
- 境界は現状 **マージ後の最長部分** + `total-2` 閾値（`がくせい` 単語で `学:2` にしない）。AzooKey 実機の「こ(1)」初期境界とは **未一致**（#4 は `こんにち|は` で運用可能）。
