## フェーズ 2: SQLite クエリパターンの共通化

### 問題

`Sources/DatabaseManager.swift`（384行）で `sqlite3_prepare_v2` + `defer sqlite3_finalize` + `sqlite3_step` のパターンが16回以上繰り返されている。

### 方針

DatabaseManager 内に private ヘルパーを2つ追加し、既存の公開APIのシグネチャは変えない。

#### `queryStrings(_:bindings:columnIndex:) -> [String]`

```swift
private func queryStrings(
    _ sql: String,
    bindings: [(Int32, String)] = [],
    columnIndex: Int32 = 0
) -> [String] {
    var stmt: OpaquePointer?
    defer { sqlite3_finalize(stmt) }
    guard sqlite3_prepare_v2(db, sql, -1, &stmt, nil) == SQLITE_OK else { return [] }
    for (idx, value) in bindings { bindText(stmt, idx, value) }
    var results: [String] = []
    while sqlite3_step(stmt) == SQLITE_ROW {
        if let ptr = sqlite3_column_text(stmt, columnIndex) {
            results.append(String(cString: ptr))
        }
    }
    return results
}
```

#### `execute(_:bindings:)`

```swift
private func execute(_ sql: String, bindings: [(Int32, String)] = []) {
    var stmt: OpaquePointer?
    defer { sqlite3_finalize(stmt) }
    guard sqlite3_prepare_v2(db, sql, -1, &stmt, nil) == SQLITE_OK else { return }
    for (idx, value) in bindings { bindText(stmt, idx, value) }
    sqlite3_step(stmt)
}
```

#### 適用対象（優先順）

| 関数 | 現状 | 移行後 |
|------|------|--------|
| `fetchHistoryExact` | prepare+step | `queryStrings` |
| `fetchHistoryPrefix` | prepare+step | `queryStrings` |
| `fetchBigram` | prepare+step | `queryStrings` |
| `fetchTrigramTop` | prepare+step | `queryStrings` |
| `deleteHistory` / `deleteBigram` | prepare+step | `execute` |

`recordHistory` / `recordBigram` は `sqlite3_last_insert_rowid` / `sqlite3_changes` を使うため手動のまま。

### 検証

```bash
xcodebuild test -scheme keynaco -destination "platform=macOS"
```

## フェーズ 3: `handle()` の責務分割

### 問題

`Sources/InputHandler.swift` の `handle()` メソッドが約200行あり、複数の責務が混在している。

### 方針

`handle()` をディスパッチャに留め、責務ごとにメソッドに切り出す。戻り値の型や呼び出し元（`InputController`）のシグネチャは変えない。

#### 切り出し候補

| メソッド | 行数目安 | 現在の場所 |
|---------|---------|-----------|
| `handleSuccessorMode(keyCode:characters:candidate:client:)` | ~30行 | `handle()` 冒頭 |
| `handleCandidateVisible(keyCode:modifiers:candidate:client:)` | ~50行 | 候補ウィンドウ表示中の分岐 |
| `handleNormalInput(keyCode:characters:baseCharacters:modifiers:client:)` | ~80行 | 通常文字入力処理 |

`handle()` 自体は各メソッドへの振り分けのみになる（~30行）。

### 注意

`handle()` は `mutating func` で `state`・`isSuccessorMode` 等を直接書き換えるため、切り出したメソッドもすべて `mutating` にする。テストのシグネチャは変えない。

### 検証

```bash
xcodebuild test -scheme keynaco -destination "platform=macOS"
```
